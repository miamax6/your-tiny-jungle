    À quoi ça sert : retrouver tes plantes, tes coches et tes notes sur ton téléphone comme sur ton PC. Tes données partent chiffrées dans un dépôt GitHub privé — ni GitHub ni personne d'autre ne peut les lire sans ta phrase secrète.

    1. Créer un jeton. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained. Only select repositories → ton dépôt privé. Permissions → Contents : Read and write. Durée : 1 an.

    3. Choisir une phrase secrète longue. Elle ne part jamais chez GitHub. Si tu la perds, les données sont irrécupérables.
